# PokeLab Dex - Aplikasi Pokédex Interaktif Menggunakan Public API

## Deskripsi Aplikasi
PokeLab Dex adalah aplikasi web interaktif yang menampilkan data Pokémon secara langsung dari Public API yaitu PokeAPI. Aplikasi ini dibuat menggunakan HTML, CSS, dan JavaScript, serta dijalankan secara lokal menggunakan XAMPP.

## Teknologi yang Digunakan
- HTML
- CSS
- JavaScript
- Fetch API
- PokeAPI
- XAMPP

## Fitur Aplikasi
- Menampilkan daftar Pokémon dari Public API
- Search Pokémon berdasarkan nama
- Filter Pokémon berdasarkan type
- Pagination data
- Detail Pokémon dalam modal
- Statistik Pokémon dalam bentuk bar
- Random Pokémon Scanner
- Compare Pokémon
- Error handling jika API gagal diakses

## Public API yang Digunakan
PokeAPI

Endpoint:
https://pokeapi.co/api/v2/pokemon?limit=300

## Cara Menjalankan Aplikasi
1. Simpan folder project di dalam:
   C:\xampp\htdocs\pokedex-api

2. Jalankan XAMPP Control Panel.

3. Start Apache.

4. Buka browser dan akses:
   http://localhost/pokedex-api
